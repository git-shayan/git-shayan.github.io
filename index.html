What the findings show

  • Missing authentication. Four of the six critical findings were unauthenticated access: OS command injection, iSCSI, Elasticsearch and an admin interface.
  • Exposed services. Public NFS shares, a DNS zone transfer, anonymous FTP and SMB enumeration, and exposed administrative and backup services.
  • Weak configuration. SMBv1 and unsigned SMB, a management platform served over HTTP, SSH password logins and an expired certificate.
  • Information disclosure. Sensitive data through Elasticsearch, application details, robots.txt and technology fingerprints.

Tools: Nmap, Metasploit, Burp Suite, Nessus, OpenVAS, Wireshark

A full test of a simulated IT/OT environment, from recon to a client-style report.

builtTeam of four, Howest

Honeypot system: Cowrie, Laravel and ELK

An SSH honeypot and a hardened web app, with every log shipped to Elasticsearch and Kibana.
  • Built the Laravel (PHP) application with registration and login, profile management, avatar upload, admin user management and security logging, backed by MariaDB.
  • Served it through Nginx with TLS and hardening, passing requests to PHP-FPM and Laravel.
  • Ran a Cowrie SSH honeypot on port 2222. It fakes an SSH environment, captures brute-force attempts and logs the commands and sessions of attackers.
  • Collected logs from Cowrie, the Laravel app, Nginx and the system with Filebeat into Elasticsearch, then explored them in Kibana.
  • Used Splunk and Wazuh to triage alerts and investigate source IPs, and pentested other teams' setups with OWASP methods.
  • Kept code, configuration and documentation in separate GitLab repositories.

Tools: Cowrie, Laravel, MariaDB, Nginx, Filebeat, Elasticsearch, Kibana, Splunk, Wazuh, GitLab

labMobile security, Howest

Android mobile security assessment

Static and dynamic analysis of an Android app, from decompiling to runtime bypass.
  • Worked with a native Android app (Kotlin, Jetpack Compose, Room, Retrofit and OkHttp) built with security flaws on purpose.
  • Static analysis: decompiled the app with JADX and Apktool, and practised modifying and rebuilding an APK.
  • Dynamic analysis: used ADB, Logcat, Frida and Burp Suite on a rooted emulator to watch runtime behaviour and API traffic.
  • Compared insecure and secure credential storage, and looked at API access-control problems such as IDOR.
  • Studied the app's root detection (test-keys, su paths, Magisk packages) and wrote a Frida script that bypassed an admin-check function.
  • Simulated a keylogger and credential exfiltration to see the attack from both sides.
  • Applied the same method in an assessment: device information, static analysis, then dynamic analysis of a provided APK on a rooted Pixel 6 Pro emulator.

Tools: Frida, JADX, Apktool, ADB, Logcat, Burp Suite, Android Studio
